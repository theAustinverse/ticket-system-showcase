# 5. 實作專案後的心得

## 最大的收穫

從零學會怎麼把想法做成系統，也學會用產品思維不斷優化，讓系統真正帶來效益。過去繁雜的行政流程全部省掉，整理票券變得更有效率。

## 最難的地方：從零開始

我對架設網站毫無概念，也沒有相關經驗，一切都是從零開始：前端、後端、資料庫的建置，串接多項 API 與 MCP 工具，以及 UI/UX 設計，都是我逐步建立起來的。

過程中我根據使用者回饋，持續找出可以優化的地方。

## 和 Claude 合作的體會

Claude 在撰寫程式、開發工具，以及串接其他工具上都非常有效率，功能強大也很齊全。只要我把遇到的問題或不確定的地方告訴它，它都會給我不錯的建議。

## 上線後的結果

使用者的反應正面，認為這套系統和以往的報名方式明顯不同。

## 下一步的規劃

我希望明年把條碼掃描系統做得更全面，讓簽到報到更有效率。
