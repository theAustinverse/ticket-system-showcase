**D2　換頁後回到頁首**

- 結果：2026-10-16 上線。
- 依據：作者回報（摘要引述）＋提交紀錄。

**D3　首頁移除聯絡欄位**

**D5　小額贊助新增加密貨幣選項**
- 狀況：作者想放上交易所的入金地址，先問「這樣會有風險嗎?」
- 選擇：作者指定只收 USDT 或 USDC（BNB Smart Chain），不需要 memo。
- 程式註解記載的考量：穩定幣不用猜幣價；選錯網路款項通常無法找回。
- 代價：不收其他幣；沒有 memo，改由贊助者貼交易哈希對帳。
- 結果：2026-10-17 上線；作者回報首頁看不到入口後，補上首屏提示。
- 依據：作者原話（摘要引述）＋提交紀錄＋程式註解。

**D6　首頁新增頭條新聞**
- 選擇：作者提供圖片；位置放在首屏主視覺下方、活動列表之前；點擊可放大。圖片載入失敗時整個區塊隱藏。
- 依據：作者的三個回答（摘要引述）＋提交紀錄（2026-10-17）。

**D7　作品公開前，遮蔽聯絡資訊**
- 作者原話（2026-11-26）：「幫我把聯絡我們裡面得資訊全部改成馬賽克文字，不要留任何真實聯絡資訊，因為我要公布作品了」
- 選擇：公開 API 直接回傳馬賽克文字（瀏覽器收到的就是馬賽克），LINE 按鈕不再是連結；後台仍是真實資料。

- 結果：後端部署約花 8 分鐘；在這段時間，前端已更新但真實資料仍可見，作者在畫面上發現並回報。
- 依據：作者原話＋提交紀錄。

**D8　作品公開前，贊助收款資訊改為星號**

### Claude 提出、作者同意

**D11　加密貨幣收款的防護做法**
- 選擇：收款地址寫在程式碼裡，不放後台欄位或環境變數；贊助者貼交易哈希，哈希唯一、記錄後不能更換；地址格式不對就整段隱藏。
- 理由（程式註解）：如果只有後台權限的人能改地址，所有贊助會被轉走且難以察覺。
- 代價：換地址必須經過提交與部署。
- 作者回應：「依照你的建議去做」（摘要引述）。

**D12　流量統計改用 Vercel Web Analytics**
- 狀況：作者想查總使用人數與點擊數；伺服器紀錄只保留約 7 天，也沒有點擊追蹤。
- 選擇：無 cookie 的 Vercel Web Analytics；用自寫載入器，避開套件版本衝突；隱私政策同步註明。
- 作者回應：「幫我開啟 Vercel Web Analytics」（摘要引述）。
- 結果：程式已上線（2026-10-17）；後台開關是否已開啟，待確認。

**D13　展示模式的實作方式**
- 選擇：遮蔽做在伺服器端，用程式碼開關控制，隨時可恢復。
- 作者回應：「上線」（2026-11-26）。這是同意發布，不是對做法的評論。
