# 6. 未來可以優化和調整的地方

這一頁列出系統目前還沒有、未來可以優化和調整的功能與規劃。已經上線的功能，請見前面各章節，特別是[第 3 節](03-architecture.md)。

## 1. 轉讓截止時，自動結束尚未接受的轉讓

**設計構想**

轉讓截止前，如果對方還沒接受，就自動退回原申請人。

**優化方向**

目前轉讓截止後，尚未處理的邀請會維持「待處理」狀態。未來在截止時自動結束這些邀請，並通知雙方。

## 2. 擴充條碼掃描報到系統

**優化方向**

明年將條碼掃描系統做得更全面，讓簽到報到更有效率。

## 3. 加強個資的加密保護

**設計構想**

讓使用者填入的個人資訊都受到加密保護，以確保資料的安全性。

**優化方向**

目前姓名、聯絡方式等個人資料欄位沒有另外加密儲存。未來對這些欄位加上加密儲存，並確認資料庫層的加密設定。

## 4. 建立個資外洩時的處理流程

**設計構想**

一旦發生個資外流，能立即刪除相關資料，確保使用者的資料安全。

**優化方向**

目前還沒有針對個資外洩的處理流程，也沒有自動刪除資料的設定。未來建立外洩時的處理流程，包含自動刪除相關資料的機制。

## 5. 刪除使用者與訂單時留下操作紀錄

**優化方向**

目前管理員刪除使用者或訂單時，沒有另外留下操作紀錄。未來刪除時也留下紀錄，方便日後追查。
