# 6. 未來可以優化和調整的地方

這一頁列出系統未來可以優化和調整的地方。每一項都先對照程式確認目前的運作方式，再說明下一步的優化方向。

## 1. 轉讓截止時，自動結束尚未接受的轉讓

**設計構想**

轉讓截止前，如果對方還沒接受，就自動退回原申請人。

**目前的運作方式**（依程式核對）

- 收票人接受前，票券的持有人不會改變。
- 每一波可以設定「轉讓截止時間」。截止後不能發起新的轉讓，也不能再接受截止前已發出的邀請；邀請可以由收票人拒絕，或由原持有人取消。
- 待處理的轉讓沒有設定期限，截止後會維持「待處理」狀態。
- 波次的銷售結束時間不影響轉讓。

截止後，票券保留在原持有人名下；尚未處理的轉讓邀請維持「待處理」狀態。

**優化方向**

轉讓截止時，自動結束尚未接受的邀請，並通知雙方。

## 2. 擴充條碼掃描報到系統

**目前的運作方式**（依程式核對）

- 每個座位都有一張專屬的入場 QR，同一張只能報到一次。
- 現場工作人員使用專屬帳號登入，用手機掃描 QR 報到。
- 有各團隊的報到名單，也可以查詢與統計報到人數。

**優化方向**

明年將條碼掃描系統做得更全面，讓簽到報到更有效率。
